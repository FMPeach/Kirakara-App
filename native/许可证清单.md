# 原生输入法组件清单

Kirakara-App 的 Windows 输入法运行包组合了 librime、Mozc 和 Zinnia。它们不适用项目
根目录的 MIT License，而是继续使用各自的上游许可证。固定版本、下载地址和文件哈希以
`native.lock.json` 为准。

## 二进制与源码轨道

普通 Windows 运行包使用 `native.lock.json` 锁定的 librime 1.13.1 官方预编译资产。
仓库同时保留从固定源码重建 librime 的维护入口，用于升级、比对和验证；源码轨道的
revision、构建选项或依赖发生变化时，需要重新生成与该产物对应的组件声明，不能把另一份
DLL 的清单直接套用过来。

Mozc 桥接和 Zinnia 静态库也按锁文件中的 revision、架构、构建模式与 SHA-256 识别。
许可证清单只能说明来源和分发义务，不能替代二进制身份校验。

## 分发要求

制作原生运行包或完整 App Release 时，应当：

- 保留 librime、Mozc、Zinnia 以及实际静态依赖的原始版权和许可证文本；
- 将运行库、数据包和手写模型的声明分别随对应产物分发；
- 保留 `SOURCES.json` 或等效来源记录，使二进制能够追溯到锁定版本；
- 在更换上游版本、编译选项或依赖后重新核对本清单。

根目录的 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 汇总整个 App 的第三方组件；
Flutter 和 Dart package 的完整声明由构建产物中的 `data/flutter_assets/NOTICES.Z` 提供。
